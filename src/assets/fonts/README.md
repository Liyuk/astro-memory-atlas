# Noto Sans SC variable font

This self-hosted WOFF2 font is Noto Sans SC, sourced from the official Google Fonts repository:

- Font: https://github.com/google/fonts/tree/main/ofl/notosanssc
- Original variable TTF: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
- License: SIL Open Font License 1.1, included as `OFL.txt`

The variable font was converted to WOFF2 without changing its glyph set. Keep this as the site's only font asset and retain the upstream license when redistributing it.
